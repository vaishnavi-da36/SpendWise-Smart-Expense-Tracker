# 💰 SpendWise — Smart Expense Tracker

> Smart Expense Tracking • Data Analytics • Budget Intelligence • Spending Insights

SpendWise is a Python-based expense analytics platform designed to help users track spending, understand financial behavior, monitor budgets, and generate actionable spending insights through an interactive dashboard.

## 🚀 Key Features

- 📂 CSV expense data upload
- ➕ Add new expenses
- 🔎 Category and payment-method filtering
- 📅 Date-range based analysis
- 💰 Total spending analysis
- 📊 Transaction count and average spending
- 🏆 Top spending category identification
- 💳 Payment-method spending analysis
- 🎯 Budget monitoring
- ⚠️ Spending threshold alerts
- 📈 Interactive data visualizations
- 🧠 Spending intelligence and insights
- 📱 Interactive Streamlit dashboard

## 📊 Analytics

SpendWise provides insights such as:

- Total expenditure
- Average transaction value
- Spending by category
- Spending by payment method
- Spending trends over time
- Highest spending category
- Budget utilization
- Threshold monitoring
